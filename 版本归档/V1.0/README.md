# 量化策略分析工具

## 功能说明

本工具用于科创100ETF（588800）的波段交易策略分析和回测。

## 主要功能

1. **测算今日操作建议** - 基于最新数据生成今日交易信号
2. **回测** - 对策略进行历史回测，计算收益率和胜率
3. **开机启动** - 可设置程序开机自动启动

## 安装依赖

```bash
pip install pandas numpy akshare
```

## 数据更新机制

### 自动数据同步

程序已集成自动数据更新功能：
- 首次运行时会自动从akshare API获取历史数据
- 每次运行"测算今日操作建议"或"回测"时，都会检查数据是否为最新
- 如果数据库中没有数据，会自动从API获取并保存

### 手动更新数据

也可以单独运行数据更新脚本：

```bash
python update_data.py
```

## 文件说明

- `main.py` - GUI主程序
- `strategy.py` - 策略核心逻辑
- `strategy_evaluation.py` - 策略评估和回测
- `update_data.py` - 独立的数据更新脚本
- `stock_data.db` - SQLite数据库，存储股票历史数据

## 策略说明

### 技术指标
- MA5, MA10, MA20 - 移动平均线
- RSI14 - 相对强弱指标
- Z20 - Z-Score（20日）
- ROC5 - 5日变化率
- Vol20 - 20日平均成交量

### 交易信号
- **+50%** - 深超卖大幅买入
- **+20%** - 回踩买入/修复启动/反转确认
- **-50%** - 标准卖出
- **-80%** - 过热区卖出/趋势破坏
- **0%** - 无信号

## 注意事项

1. 确保网络连接正常以获取最新数据
2. 首次运行需要较长时间获取历史数据
3. 数据会自动保存到`stock_data.db`文件中
4. 建议定期运行程序以保持数据同步到今日
