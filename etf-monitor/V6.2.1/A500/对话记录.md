## 3. strategy.py -- 策略流水线（核心决策引擎）

**文件：** `f:\windows10桌面\量化\V6.1\strategy.py`（共619行）

**核心类：** `V6Strategy`

**架构层级（7层流水线）：**

```
数据预处理 (indicators.py)
    |
Layer 1: Market Regime 检测 (regime_detector.py)
    |  -- 输出 Bull / Bear / Range / Unknown
Layer 2: Behavior Detection (behavior_detector.py)
    |  -- 检测9种买卖行为，输出buy_behaviors/sell_behaviors
Layer 3: EmotionBuilder (emotion_builder.py)
    |  -- 替代原CrowdPsychology，PCA/ICA/Weighted融合
    |  -- 输出psych_state + emotion_score + emotion_improving
Layer 4: Event Engine + Lifecycle (event_engine.py)
    |  -- 行为生命周期管理 Candidate->Confirmed
    |  -- 包含Time Decay
Layer 5: Reward/Risk Evaluation (reward_risk.py)
    |  -- 多因子评分，reward_score(0-50) / risk_score(0-50)
Layer 6: Evidence Engine (evidence_engine.py)
    |  -- 多源融合：Rule(0.30) + Replay(0.25) + ML(0.35) + Emotion(0.10)
    |  -- 输出 buy_score / sell_score
Layer 7: Position Management (position_manager.py)
    |  -- 由回测引擎调用，不在此处执行
```

**买卖信号生成逻辑（`_compute_v6_score` 方法，第249-375行）：**

- **买入评分公式：**
  ```
  raw_buy = behavior_norm * 0.30 + final_conf * 0.15 + reward_score * 1.20
  buy_score = raw_buy * regime_buy_multiplier
  ```

- **卖出评分公式：**
  ```
  raw_sell = behavior_norm * 0.30 + final_conf * 0.15 + risk_score * 1.35
  sell_score = raw_sell * regime_sell_div
  ```

- **情绪修正：** Panic时买入+10%；Euphoria时卖出+15%且买入-20%；Exhaustion时卖出+25%

- **评分到仓位映射：** 通过`score_to_target_position()`函数将评分映射为0%-75%的目标仓位

**V6.1 升级点：**
1. ML模型默认启用，每10笔交易自动在线重训练（RandomForest, 100棵树, 最大深度5）
2. Platt概率校准 + 校准变差自动禁用
3. Replay Learning使用(Regime, Behavior, Psychology)三维键 + Laplace平滑
4. 证据链路透明化：每笔交易记录完整的Evidence Engine分解

## 4. backtest.py -- 回测引擎

**文件：** `f:\windows10桌面\量化\V6.1\backtest.py`（共835行）

**核心类：** `V6Backtest`

**回测流程（`run` 方法，第66-353行）：**

1. **初始化：** 设置初始资金(10000)、初始仓位(70%)，按start_date切片数据
2. **逐日迭代：**
   - 从signal_map获取当日评分和行为
   - 统计行为计数、情绪双确认、Evidence Engine追踪
   - 计算目标仓位（`score_to_target_position`）
   - 仓位偏离超过阈值时执行交易
   - **V6.1最低持仓检查：** 买入后至少`MIN_HOLD_DAYS=7`天才能卖出
3. **交易记录：**
   - 买入时记录entry_price/entry_reason/entry_regime/entry_psychology/entry_evidence
   - 卖出时计算pnl_pct，记录完整的入场/出场因子
   - 成功后调用 `strategy.record_trade_result()` 更新行为记忆库
   - 收集ML训练样本（通过`FeatureBuilder.build_from_trade`）
4. **回测结束平仓：** 未完成交易按最后收盘价强制平仓

**绩效指标（`_compute_results`，第355-472行）：**

| 指标 | 计算方式 |
|------|----------|
| benchmark_return | (end_price - start_price) / start_price |
| strategy_return | (end_equity - start_equity) / start_equity |
| excess_return | strategy_return - benchmark_return |
| max_drawdown | (equity - cummax) / cummax 的最小值 |
| sharpe_ratio | avg_daily_return / std_daily_return * sqrt(252) |
| sortino_ratio | (annualized_return - 0.02) / downside_dev |
| calmar_ratio | annualized_return / abs(max_drawdown) |
| profit_factor | total_profit / total_loss |
| win_rate | winning / total_trades |
| kelly | w - (1-w) / (avg_w / avg_l) |
| expectancy | win_rate * avg_profit + (1-win_rate) * avg_loss |
| avg_hold_days | 平均持仓天数 |

**导出功能：**
- `export_all()`: 导出完整JSON（绩效/交易/每日信号/净值/评分历史/证据链），写入 `backtest_records.json`
- `export_trades()`: 导出为JSON或CSV
- `print_trade_factors()`: 控制台打印单笔交易的Evidence Engine促成因子明细
- `_extract_evidence_factors()`: 将Evidence Engine输出解析为可读结构（rule/replay/ml/emotion四个证据源逐项分解）

**主要特性：**

1. **多核并行：** 使用 `ProcessPoolExecutor` + `spawn` 上下文，每个子进程独立运行 V6Strategy + V6Backtest，自动检测CPU核心数
2. **断点续算：** 基于SHA256指纹（参数网格 + 数据行数/首尾日期 + start_date）持久化到 `.grid_search_checkpoint.json`，每10个组合保存一次，中断后自动续算，参数/数据变更自动使旧断点失效
3. **原子写入：** 先写 `.tmp` 再 `os.replace`，防止崩溃损坏文件
4. **指标预计算：** 主进程一次性计算所有指标，worker子进程直接复用，避免重复计算
5. **Pareto分析：** 多目标非支配排序，优化维度：strategy_return, sharpe_ratio, max_drawdown（越小越好）, calmar_ratio, win_rate, total_trades（适中的交易次数更好）
6. **自动关机：** 搜索完成后弹窗提示，10秒倒计时自动关机（无人值守模式），可取消

**便捷函数：**
