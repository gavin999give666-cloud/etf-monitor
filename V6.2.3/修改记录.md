## 二、数据更新修复（data_updater.py）

### 1. 已最新短路（新增）

**文件**：`A500/data_updater.py`（约第 450 行）

```python
start_dt = datetime.strptime(last_date, '%Y-%m-%d') + timedelta(days=1)
if start_dt.date() > datetime.now().date():
    print(f"数据库已包含今日({last_date})数据，无需获取")
    return True
```

**背景**：数据库已含今日数据时，`最新日期+1 > 今日` 会形成 `20260819 至 20260818` 的倒挂区间，原代码不检查直接打印并发起空请求。

## 三、空心建议标记（evaluation.py + config.py）

### 设计语义

- 画在所有满足条件的历史日（非仅最新日），未来数据不改变已画标记
- 判定与回测持仓无关 —— 展示策略"想要"执行的交易，不受持仓锁定影响
- 用户实际持仓不会与程序完全一致，目标是复盘策略能否在过去踩准每个交易机会
- 为避免信息过载，仅当买卖绝对分高于阈值时才绘制
- 空心灰圆（持有）因逻辑复杂，按要求已忽略

### 判定标准（最终版：净分区判定 + 绝对分阈值）

**文件**：`A500/config.py`（约第 308 行）新增

```python
# 空心建议标记阈值：绝对分数 >= 该值时，在回测图上画空心建议标记
# （实用满分按100分计，此阈值即"理论满分的60%"；与回测持仓无关）
REC_MARKER_THRESHOLD = 60
```

相关既有参数：`SCORE_HOLD_ZONE = 15`

**文件**：`A500/evaluation.py`（plot_results 信号收集，约第 338 行）

```python
# 空心建议标记：策略"想要"执行的买卖（与回测持仓无关，不受持仓锁定影响）
# 判定标准：绝对分数 >= config.REC_MARKER_THRESHOLD 且净评分突破 ±SCORE_HOLD_ZONE
# （与策略目标仓位映射一致；同日买卖双高但净分在HOLD区内的矛盾日不画，每天最多一个标记）
rec_buy_dates, rec_buy_prices = [], []
rec_sell_dates, rec_sell_prices = [], []
for ds in bt.daily_signals:
    date = ds.get('date')
    if date is None or date not in df_plot.index:
        continue
    price = df_plot.loc[date, 'close']
    net = ds.get('buy_score', 0) - ds.get('sell_score', 0)
    if ds.get('buy_score', 0) >= config.REC_MARKER_THRESHOLD and net > config.SCORE_HOLD_ZONE:
        rec_buy_dates.append(date)
        rec_buy_prices.append(price * 0.991)  # 略低于收盘价，避免与实心成交标记重叠
    elif ds.get('sell_score', 0) >= config.REC_MARKER_THRESHOLD and net < -config.SCORE_HOLD_ZONE:
        rec_sell_dates.append(date)
        rec_sell_prices.append(price * 1.009)  # 略高于收盘价
```

绘制（约第 377 行）：

```python
# 空心建议标记（买入=空心绿三角，卖出=空心红倒三角）
if rec_buy_dates:
    ax1.scatter(rec_buy_dates, rec_buy_prices, facecolors='none', edgecolors='#00C853',
                s=50, marker='^', linewidths=1.2, zorder=4, label='买入建议(空心)')
if rec_sell_dates:
    ax1.scatter(rec_sell_dates, rec_sell_prices, facecolors='none', edgecolors='#FF1744',
                s=50, marker='v', linewidths=1.2, zorder=4, label='卖出建议(空心)')
```

实心成交标记（`executed=True`）绘制逻辑保持不变。

### 为何不用 target_position 判定

`score_to_target_position(buy_score, sell_score, current_position)`（scoring_engine.py）依赖当前持仓（卖出区按比例减仓、HOLD 区维持当前仓位），不能用其变化作为"忽略持仓"判定标准，故改为纯分数净评分方案。

### 验证结果

- 同日双标记冲突：25 天 → **0 天**（if/elif 保证每天最多一个空心标记）
- 买入标记：65 → **39**；卖出标记：65 → **18**
- 典型被过滤例：7/8 日 buy=64.8 vs sell=64.4（净分仅 +0.4，落在 HOLD 区，不画）
- 8/14 有买入标记（buy=100.3, net=+95.4）；8/18 无空心标记（buy=43.3 / sell=5.1 均不足阈值）
