## 一、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux v22 (Ubuntu 22.04 / Debian 12 等) |
| Python | 3.8+（推荐 3.10+） |
| 网络 | 能够访问 akshare API（东方财富数据源）和 Bark API（api.day.app） |
| 磁盘 | 至少 200MB 可用空间 |

## 二、快速部署

### 步骤 1：上传文件到服务器

```bash
# 将整个 V6.2.3_Linux 目录上传到服务器
scp -r V6.2.3_Linux/ user@your-server:/home/user/
```

### 步骤 2：运行安装脚本

```bash
cd /home/user/V6.2.3_Linux
bash setup.sh
```

安装脚本会自动：
- 创建 Python 虚拟环境
- 安装所有依赖（pandas, numpy, akshare, scikit-learn 等）
- 创建日志目录
- 初始化数据库
- 生成默认配置文件

### 步骤 3：配置 Bark 推送

编辑配置文件，填入你的 Bark Key：

```bash
nano deploy_config.json
```

```json
{
    "bark_url": "",
    "bark_key": "你的Bark_Key在这里",
    "stock_code": "563360",
    "db_path": "src/stock_data.db",
    "max_data_retries": 3,
    "max_signal_rounds": 3,
    "retry_wait_seconds": 30,
    "timeout_seconds": 120
}
```

> **获取 Bark Key**：在 iPhone 上安装 Bark App → 打开 App → 复制显示的 URL 中的 Key 部分（如 `https://api.day.app/xxxxx` 中的 `xxxxx`）

### 步骤 4：初始化数据

```bash
source venv/bin/activate
python3 -c "
import sys; sys.path.insert(0, 'src')
from data_updater import full_refresh_data
full_refresh_data()
"
```

首次获取全部历史数据约需 1-3 分钟，之后每日增量更新仅需数秒。

## 三、配置定时任务（每日 14:40）

```bash
crontab -e
```

添加以下行：

```
40 14 * * 1-5 bash /home/user/V6.2.3_Linux/start.sh >> /home/user/V6.2.3_Linux/logs/cron.log 2>&1
```

> **说明**：`1-5` 表示周一至周五，股市交易日执行。每天 14:40（收盘后10分钟）自动运行。

### crontab 验证

```bash
# 查看当前定时任务
crontab -l

# 查看定时任务执行日志
tail -f logs/cron.log
```

## 六、运行流程说明

```
crontab (14:40) 
    ↓
start.sh（激活venv，调用run_daily.py）
    ↓
run_daily.py 主流程：
    ┌─────────────────────────────────┐
    │  第1轮                            │
    │  1. 数据更新（最多重试3次）          │
    │  2. 信号生成                        │
    │  3. 日期校验                        │
    │     ├─ 通过 → 进入推送              │
    │     └─ 失败 → 删除最新数据，进入第2轮 │
    ├─────────────────────────────────┤
    │  第2轮（如有必要）                  │
    │  同第1轮流程                        │
    ├─────────────────────────────────┤
    │  第3轮（如有必要）                  │
    │  同第1轮流程                        │
    └─────────────────────────────────┘
    ↓
Bark推送
```

### 容错机制

| 场景 | 处理方式 |
|------|----------|
| 数据API请求失败 | 自动重试3次，每次间隔递增 |
| 信号日期不是当日 | 删除最新数据 → 等待30秒 → 重新获取 |
| 信号生成异常 | 捕获异常 → 写日志 → 下一轮重试 |
| Bark推送失败 | 捕获异常 → 写日志 → 不影响主流程退出 |
| 非交易日（周末） | 自动检测，允许信号为最近交易日 |
| 全流程失败 | 写入错误日志 → 程序退出码1 → cron可感知 |

## 八、常见问题

### Q1: akshare 数据获取失败
```
检查网络连接: curl -I https://push2his.eastmoney.com
可能是东方财富API限流，等待30秒后自动重试
```

### Q2: Bark 收不到推送
```
1. 确认 deploy_config.json 中 bark_key 正确
2. 确认服务器可以访问 api.day.app
3. 手动测试: curl "https://api.day.app/你的key/测试标题/测试内容"
```

### Q3: crontab 未执行
```
1. 检查 cron 服务: systemctl status cron
2. 检查 crontab 配置: crontab -l
3. 查看日志: cat logs/cron.log
4. 确保 start.sh 有执行权限: chmod +x start.sh
```

### Q4: 虚拟环境找不到
```
重新运行安装脚本: bash setup.sh
或手动创建: python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
```
