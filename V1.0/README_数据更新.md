# 量化策略分析工具 - 数据更新说明

## 问题描述
之前回测数据显示只到4月24日，是因为缺少数据自动更新机制。

## 解决方案
已添加数据更新功能，支持从东方财富API自动获取最新的股票数据。

## 使用方法

### 1. 安装依赖
如果尚未安装akshare，请运行：
```bash
pip install akshare
```

或者使用requirements.txt：
```bash
pip install -r requirements.txt
```

### 2. 更新数据

#### 方式一：通过GUI界面（推荐）
启动程序后，点击以下按钮：
- **更新数据**：增量更新，只获取上次更新日期之后的新数据（快速）
- **完全刷新**：清空所有数据并重新获取全部历史数据（耗时较长，仅在数据异常时使用）

#### 方式二：命令行运行
```bash
python data_updater.py
```
然后选择：
- 选项1：增量更新（推荐）
- 选项2：完全刷新

### 3. 查看最新数据
更新完成后，点击"回测"按钮即可看到包含最新数据的回测结果。

## 数据存储
- 数据库文件：`stock_data.db`（SQLite格式）
- 存储位置：与exe文件或脚本同目录
- 数据表：`stock_data`
- 字段：date, open, high, low, close, volume

## 注意事项
1. 首次使用或数据异常时，建议使用"完全刷新"功能
2. 日常使用建议使用"增量更新"，速度更快
3. 数据更新需要联网
4. 如果API访问失败，可能是网络问题或API限制，请稍后重试

## 技术实现
- 数据源：akshare库（东方财富API）
- 股票代码：588800（科创100ETF）
- 更新策略：增量更新，避免重复下载
- 数据库：SQLite，轻量级无需配置
